Route WordPress Email Through
MXRoute's HTTP API.

MXRoute Mailer intercepts wp_mail() and sends email through MXRoute's HTTP API on port 443 or SMTP — automatically choosing the best transport for each email. For hosting environments where outbound SMTP ports are blocked.

HTTPS API transport — no SMTP required Automatic SMTP fallback Memory-aware batch sending Multisite compatible
