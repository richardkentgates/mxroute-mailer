WordPress Plugin · HTTPS API · SMTP Fallback

Route WordPress Email Through
MXRoute's HTTP API.

MXRoute Mailer intercepts wp_mail() and sends email through MXRoute's HTTP API on port 443 or SMTP — automatically choosing the best transport. Solves the common problem of hosting providers blocking outbound SMTP ports (25, 465, 587).

📧 Smart-switch transport — API or SMTP 🔄 Email queue — Background WP-Cron processing 📎 Persistent attachment storage — Reliable re-delivery 📊 Email logging — Full logs with search and filtering 🔧 Test email tool — Verify configuration instantly
